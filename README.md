**3400 Container - LAMP Development Stack with phpMyAdmin and Composer preinstalled.**

Prerequisites: Visual Studio Code and Docker Desktop (or you can launch it in GitHub Codespaces to run it in your browser)

To use this repository, clone it to your local computer, then open the project folder with VSCode.

To access your web application, use the following link:

http://localhost

To access phpMyAdmin, use the following link (User=web3400 Pwd=password):

https://localhost:8001
